# ATLAS IFRS — Application Reference

An independent trilingual (Italian / English / German) technical reference site for practical application of IFRS, IAS and sustainability standards across industries. Responsive calm professional design.

## Current scope
- Searchable catalog of 46 standard entries.
- Detailed applied notes and cases for IFRS 9, IFRS 10, IFRS 13, IFRS 15, IFRS 16, IAS 12, IAS 36.
- Other entries are explicitly **overview placeholders** pending detailed technical review, not complete IFRS guidance.
- Translated application notes are present for the seven detailed entries; the technical cases are currently in English.
- Interpretations IFRIC/SIC and comprehensive legal/endorsement tracking remain future work.
